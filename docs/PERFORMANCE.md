# 压力测试与性能边界

0.2.0 使用 28–48dp 随缩放变化的标记，数量角标保持可读，较大数量用 k/m 简写，详情保留精确数量。聚合半径大于标记对角线并留 8dp 间隔。中国显示使用完整边界与简化点文字筛选，道路文字避免复杂整线国界包含测试；视口约束依据原生投影。Android 17 的完整全国增强 ZIP 导入及成都渲染约 69 秒，仅为本机模拟器结果。

2026-11-02 已在 Windows / Robolectric API28、原生图片解码下实际生成 JPEG 副本和 SQLite 数据，三档均验证地点、原图、缩略图数量及记录关联。测试照片为代码生成的合法测试图，不进入最终应用，也不冒充用户作品。

原始结果见 deliverables/photomap-stress.json。这些是开发机上的实际文件与数据库测试，**不是 6GB Android 手机性能数据**。图片为 64×48 测试 JPEG，不等于对一万张高分辨率实拍照片连续浏览的验证。

core 测试另覆盖 100/500/1000 地点的聚合数量守恒、1000 个同坐标地点不丢失、缩放拆分、平移封面稳定和 Long 计数。Android 原生 instrumentation 验证单批导入、旋转 EXIF、SQLite 重启、编辑、备份恢复及原相册文件保留。

已采用串行后台导入、缩略图预生成、只绘制可见聚合、相机空闲后聚合、取消过期任务、稳定图标差异更新、数据库索引、32 MiB 内存预览缓存和 96 MiB 磁盘预览缓存。地图瓦片由 Native 按需读取，未在内存中加载全国文件。

模拟器为 Windows WHPX、1080×1920：Android 11 ATD / 2GB RAM，以及 Android 17 API37 / 4GB RAM / 16 KB 内存页。最终采用 AMD Radeon RX 6700S 主机 OpenGL ES 渲染。软件 SwiftShader 曾出现标签、虚线及照片图标纹理缺失，切换主机 GPU 后恢复。Android 11 ATD 默认关闭绘制且缺少 DocumentsUI，测试时显式开启绘制；Android 17 标准镜像已验证系统照片选择器和 SAF 导出界面。

模拟器用于发现兼容及界面故障，不能作为骁龙手机 60 FPS、功耗或内存达标的证据。Activity 的 am start 耗时也不等于全国底图首屏完成时间，未用它冒充需求中的冷启动达标结果。

仍待旧旗舰/中端真机记录冷启动、首启释放时间、地图帧时间、P95/P99、GC、全部原生/GPU 内存、瓦片 IO、30 分钟稳定性、批量大图浏览、低空间和杀进程恢复。需求中的 2–4 秒、300ms、60 FPS 为目标，当前不宣称达标。
