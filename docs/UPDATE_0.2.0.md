## 版图更正

用户提供的 [版图参考](../版图.jpg) 印有 GS(2019)1818。未把这幅栅格参考图伪装成可精细选点的矢量图，也未将其审图号赋给应用。

撤销了开发中不适用的 Natural Earth 中国裁切轮廓。改用 chinese-global-compliant-geodata 固定提交 3cf3485789876c37be6193bf2848cf9aaa40f758 的中国数据。该项目标注 MIT、WGS84，声明源于天地图。保留全部 34 个省级区域及 8 个境界线要素，包含南海岛屿和相关境界线；陆地省级多边形合并只用于显示遮罩，完整原始顶点仍用于边界绘制。省名位置从各省多边形内部计算，没有混入 GCJ-02 坐标。

重点位置检查包括藏南达旺、阿克赛钦、台湾、钓鱼岛、香港与澳门。使用者提供的标准图是核对参考；第三方矢量整理数据和修改后的交互地图仍需正式规范性审核，清单继续记录 boundaryReviewPassed=false。

## 使用全国增强包

1. 覆盖安装 0.2.0 APK，保留已有作品。
2. 把 China-streets-Z13.zip 拷入手机；不要解压后逐个导入文件。
3. 数据 → 导入地区精细地图包 → 选择 ZIP，等待复制和校验完成。
4. 进入对应缩放与覆盖区域后自动使用增强图。北京街道图覆盖内继续优先使用内置 Z15。
5. 成功导入后可删除原 ZIP。移除地图包不会删除作品，作品备份不重复包含地图。

APK 大小与 SHA-256 以 deliverables/BUILD_INFO.txt 和 SHA256SUMS.txt 为准。数据源覆盖、标签缺失和测绘精度仍受上游数据限制，不承诺与商业地图景点库完全一致。
