# 架构与数据安全

主界面 MainActivity 使用 Compose；PhotoMapEngine 独立管理 MapLibre View 生命周期、相机、地图资源和照片聚合。RecordEditor、PhotoViewer 为独立界面组件，详情使用可拖拽 Bottom Sheet，没有底部多 Tab 导航。旋转和倾斜地图手势关闭，竖屏为当前适配策略。

core 模块是纯 Kotlin：PhotoClustering 采用稳定 ID 排序和屏幕距离网格；同坐标不同 ID 全部保留，聚合计数累加照片数并使用 Long，封面由会话种子和成员集合确定。相机空闲后聚合，拖动过程中不访问数据库、不解码原图；仅为可见聚合创建 SymbolLayer 图标，未变成员和封面复用图标。选中地点有边框高亮。

Library 使用 Android SQLiteOpenHelper，数据库版本 1，保留 locations → records → photos 级联外键关系，建立坐标、记录关联、照片排序、日期和文件哈希索引。EXIF 相机、镜头、光圈、快门、ISO、方向及 GPS 等保存于照片 exif_json，宽高、时间、路径与哈希单独存储；手动补充或更正的参数另存 manual_parameters，保留读取到的原始 EXIF。照片 GPS 和地点坐标均明确为 WGS84；非 WGS84 地图包拒绝导入，没有混用 GCJ-02。

原图在 filesDir/library/originals 持久化，缩略图在 thumbnails，数据库只存相对路径。导入串行在 IO 线程进行，按可解码格式读取 EXIF、校正方向和生成最长边 256px 缩略图；一张失败不影响其余照片，重复文件提示但保留。单文件上限 512 MiB，并检查剩余空间。导入文件验证完成后才关联数据库；保存使用事务，未保存副本取消时删除，进程中断遗留副本在下次进程启动清理。

照片查看使用 Coil，预览缓存内存上限 32 MiB、磁盘缓存上限 96 MiB。全屏按 2048px / 4096px 两档加载当前照片，最大 6 倍缩放，未一次解码多张原始大图。当前不提供任意倍率原始像素分块浏览，RAW 可否解码由设备决定，失败有提示。

ZIP 备份包含版本化清单、文件大小、SHA-256、数据库与全部原图。导出在同一仓库互斥锁内关闭数据库后读取完整文件，随后重新打开。恢复先在 staging 目录解包，校验路径、重复文件、累计大小、可用空间、全部哈希、SQLite 版本/必需字段/完整性/关联、日期与坐标，并重建缩略图。全部通过后关闭旧库、原目录重命名为 previous、切换 staging，再移除旧目录；如果切换失败则退回，进程在两次目录切换之间终止时下次启动恢复 previous。

应用无账号、云端照片存储、定位、广告、遥测或后台服务。离线版无 INTERNET 权限。联网版的 MapLibre 客户端限制为指定地图服务的 HTTPS GET 或 HEAD 请求。两版通过系统选择器读取用户选定的照片，并保留 MapLibre 所需的 ACCESS_NETWORK_STATE。

Application 持有仓库与地区包管理器，避免 Activity 重建时重复清理正在导入的文件。系统自动云备份和设备迁移关闭，作品由用户显式 ZIP 导出。地区地图与作品目录分开，地图移除不影响作品。

StartupDiagnostics 在私有目录记录最近一次 Java 未捕获异常，并保留系统默认异常处理。地图初始化前同步提交版本与时间标记，样式准备后移除。Android 11 及以上仅在存在对应标记且 ApplicationExitInfo 确认为崩溃时显示恢复页，用户强制停止或正常退出不触发。Java/链接初始化异常直接进入恢复页，系统原生崩溃在下次启动读取退出原因；可手动重试或经 SAF 导出设备/API/ABI/内存页/异常摘要，不包含照片和数据库内容。

ChinaMapLabels 在样式载入后、深色变换前应用中国显示参考。完整 34 个省级名称从 Z3.25–8 同级显示，国家层不单列台湾。原始 PMTiles 保持不变；中国省界、国界与南海境界线另用注明 WGS84 的参考源。道路文字位于显示遮罩之前，点文字使用简化几何判断，省级与海域参考位于遮罩之后，避免逐条道路执行复杂国界包含计算。

MapViewport 将相机范围与原生投影的可见边界结合，设置最小缩放并约束越界拖动；摄影坐标按数据覆盖范围校验，不把陆地轮廓当作海域摄影禁区。标记为随缩放变化的 28–48dp，数量角标的字体单独适配，聚合半径覆盖标记对角线并留余量；选点时隐藏标记并查询附近可见名称。

离线 APK 内置全国 Z10 街道、周边背景和 Z7 卫星概览。全国 Z15 街道与城区精细影像同装在一个独立 ZIP 中。导入首先根据 fileSizes 预检空间，复制进度每 200ms 更新一次，随后进行全量哈希与结构校验。同一会话缓存已加载样式，避免平移时重复校验大型包。地图的详细来源和覆盖见 [地图数据](MAP_DATA.md)。
