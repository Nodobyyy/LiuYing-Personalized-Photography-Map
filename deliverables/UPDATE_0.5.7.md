# 留影 (PhotoMap) v0.5.7 更新报告

- **版本信息**：`0.5.7` (`versionCode = 15`)
- **安装包路径**：`deliverables/LiuYing-0.5.7-online-debug.apk`
- **安装包体积**：`502.07 MB`（远低于 1 GB 上限，已通过 Android 15/17 `16 KB` 页面对齐校验）
- **SHA-256**：`e4c22ae7d67be38db73ebf5a6fc4809e830b8e476da191c6a6a27a56b42c1b8d`

## 1. 卫星底图国内直连极速加载（方案 A）
- **切换至 Esri / ArcGIS World Imagery 全球节点**：将在线卫星底图数据源由原先海外慢速的 EOX（国内直连单瓦片耗时 ~2500ms）切换为国内免 VPN 直连极速响应的 **Esri / ArcGIS World Imagery** 双域名负载均衡节点（`services.arcgisonline.com` + `server.arcgisonline.com`，单瓦片响应降至 ~450ms，提速约 **5~6 倍**）。
- **原生 WGS-84 坐标无偏移**：采用国际标准 WGS-84 坐标投影，与内置中国离线底图、省市国界线及照片 EXIF GPS 坐标严丝合缝，无需 GCJ-02 纠偏。
- **更高清晰度（最高 Z17）**：在线卫星影像最高原生缩放级别由 Z14 提升至 **Z17**，放大查看建筑、街道与地貌细节更清晰。

## 2. 缩放零黑屏与渲染流畅度优化
- **本地概览图全层级托底（Overzoom 零黑屏）**：移除内置中国 Z0–Z7 离线卫星概览图层（`satellite-overview.pmtiles`）的 `maxzoom` 隐藏限制。在放大至 Z8+ 加载在线高清瓦片期间，始终保留本地低清卫星图作为底层托底背景，彻底消除快速缩放时的黑屏/白块闪烁。
- **瓦片平滑渐显过渡**：为在线卫星图层启用 `200ms` 栅格淡入动画（`raster-fade-duration: 200`），瓦片加载完成时平滑过渡，视觉更柔和。
- **动态预取层级控制（`PrefetchZoomDelta`）**：在矢量街道模式下保持 `prefetchZoomDelta = 4` 以兼顾地球视图，切换到卫星模式时动态收紧为 `1`，避免跨多级预取几十张大图挤占当前视野带宽，让当前屏幕瓦片秒出。

## 3. 网络管线并发与预热加速
- **连接池并发翻倍**：将 `MapNetwork` (OkHttp Dispatcher) 最大并发请求数提升至 `48`，单域名并发由默认 `5` 提升至 `16`，一屏 12~20 张卫星瓦片可一次性并行拉取，不再排队等待。
- **启动异步 TLS 预热**：App 启动初始化地图网络时，后台自动对 ArcGIS 卫星节点发起轻量级 `HEAD` 预热请求，提前完成 DNS 解析与 TLS 1.3 握手，首次点击切换“卫星”底图即可零延迟拉取瓦片。
